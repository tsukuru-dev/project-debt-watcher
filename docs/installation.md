# Installation

Scaffold only: no executable features or dependency toolchain have been implemented yet.

The planned package supports local installation, global installation, and npx through one executable named `debt-watcher`. Consumers require Node.js/npm and Git. See `../Agent.md` for the complete requirements.

During development, the next step is to choose and install the TypeScript build dependencies and add build, type-check, and test scripts. The current package manifest intentionally has no dependencies or lifecycle hooks. npm generates `package-lock.json`; do not hand-edit it.

For consuming projects, confirmed team setup will create or reuse the shared config, add the local development dependency and `debt-watcher` npm script, and let npm update the package files. Commit the shared config, `package.json`, and `package-lock.json`; ignore `node_modules/`.

Before release, verify the compiled executable from the packaged archive. `dist/` is generated by the build, not maintained by hand.
